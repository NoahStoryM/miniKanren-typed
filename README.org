* Installation
Install the package with ~raco pkg install --auto miniKanren-typed~.

* Documentation
See the [[https://docs.racket-lang.org/miniKanren/index.html][online documentation]], or run
~raco docs miniKanren~ after installing the package.

* Usage
Each edition of /The Reasoned Schemer/ has its own module.  The
first edition (2005) is provided by ~typed/miniKanren/trs1~:

#+begin_src racket
#lang typed/racket/base
(require typed/miniKanren/trs1)
(run* (q) (conde [(== q 'red)] [(== q 'green)]))
#+end_src
