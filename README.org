* Installation
Install the package with ~raco pkg install --auto miniKanren-typed~.

* Documentation
See the [[https://docs.racket-lang.org/miniKanren/index.html][online documentation]], or run
~raco docs miniKanren~ after installing the package.

* Usage
Each edition of /The Reasoned Schemer/ has its own module:
~typed/miniKanren/trs1~ for the first edition (2005) and
~typed/miniKanren/trs2~ for the second edition (2018).  The two
modules export many of the same names, so require only one of them, or
use ~prefix-in~.

#+begin_src racket
#lang typed/racket/base
(require typed/miniKanren/trs1)
(run* (q) (conde [(== q 'red)] [(== q 'green)]))
#+end_src

#+begin_src racket
#lang typed/racket/base
(require typed/miniKanren/trs2)
(defrel (coloro c) (conde [(== c 'red)] [(== c 'green)]))
(run* q (coloro q))
#+end_src
